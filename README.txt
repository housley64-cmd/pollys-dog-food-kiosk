POLLY'S PETS DOG FOOD FINDER - STARTER TEST

This is the first test version for the Android kiosk.

FILES
-----
index.html  = main page
style.css   = appearance
app.js      = touch navigation

HOW TO TEST ON A COMPUTER
-------------------------
1. Put all three files in the same folder.
2. Double-click index.html.
3. It should open in Chrome.
4. Tap/click any main button.
5. A test screen should appear.
6. Press HOME or Back to Dog Food Finder to return.
