  working main category tabs, and the redesigned Shop by Brand page.

GitHub upload:
1. Extract this ZIP on the kiosk/computer.
2. Open your GitHub repository.
3. Choose Add file > Upload files.
4. Drag ALL files from inside this extracted folder into the repository upload area.
5. These files should replace/update the kiosk root files.
6. Wait for the upload list to finish processing.
7. Scroll to the bottom and choose Commit changes.
